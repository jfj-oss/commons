These three files are the web UI's fonts (app/ui/fonts/*.woff2) decompressed to TrueType with `woff2_decompress`,
because GPUI's text system does not read woff2. Nothing else about them is changed. Their licences are the ones in
app/ui/fonts: LICENSE-Bellefair.txt, LICENSE-Figtree.txt, LICENSE-IBM-Plex-Mono.txt (all SIL Open Font License).
