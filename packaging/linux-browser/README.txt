Megatron for Linux, browser version

Same app, shown in a Brave, Chrome, Chromium or Edge window instead of its own. Smoother on many Linux setups
(NVIDIA cards, 4K screens) than the desktop app.

1. Unpack this file.
2. In the folder, run:  ./install.sh
3. Open Megatron from your app menu.

It does not update itself: download it again from the same page for a newer version.
To stop its background part:  megatron --stop
